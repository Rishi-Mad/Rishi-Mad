**Tech Stack**: Flask API · React · TypeScript · Tailwind · T5/BLIP · SQLite · Vite

**Links**: 
- 🔗 [Repo](https://github.com/Rishi-Mad) *(coming soon)*

<details>
  <summary><b>Features</b></summary>

- **Smart Summarization**: T5-powered text summarization with keyword extraction and paraphrasing
- **Visual Q&A**: BLIP model for answering questions about diagrams, charts, and equations
- **Flashcards**: Spaced repetition system for optimal retention
- **Adaptive Quizzes**: Dynamic difficulty adjustment based on performance
- **Analytics Dashboard**: Track progress, identify weak areas, and monitor study patterns
</details>

### <span style="color: #E6A8C2;">3. Fit Friend</span> ![Status](https://img.shields.io/badge/status-finished-9B7EBD?style=flat)

AI-powered form coach using **MediaPipe pose detection** for real-time **form analysis** across multiple exercises (squats, curls, push-ups, planks). Features form scoring, issue detection, key-frame capture, and downloadable workout reports.

**Tech Stack**: Python · MediaPipe · OpenCV · React

**Links**: 
- 🔗 [Repo](https://github.com/Rishi-Mad) *(coming soon)*

<details>
  <summary><b>How It Works</b></summary>

1. **Frame Extraction**: Capture video frames and detect 33 pose landmarks using MediaPipe
2. **Exercise Detection**: Automatically identify exercise type and compute joint angles
3. **Form Analysis**: Score form quality, detect common issues, and generate personalized recommendations
4. **Report Generation**: Export comprehensive report with key frames and improvement suggestions
</details>
