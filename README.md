### 3. RISC-V CPU Simulator ![Status](https://img.shields.io/badge/status-in%20progress-5B9BD5?style=flat) ![Visibility](https://img.shields.io/badge/visibility-private-7B8794?style=flat)

Low-level CPU simulator implementing RISC-V architecture with support for custom instructions and pipeline visualization.

**Tech Stack**: C · RISC-V Assembly

<details>
  <summary><b>Implementation Details</b></summary>

- **Pipeline Stages**: Fetch, Decode, Execute, Memory, Writeback
- **Hazard Detection**: Data and control hazard handling
- **Custom Extensions**: Support for custom RISC-V instructions
- **Debug Interface**: Step-through execution and register inspection
</details>

### 4. Fit-Friend ![Status](https://img.shields.io/badge/status-finished-6FA8DC?style=flat) ![Visibility](https://img.shields.io/badge/visibility-public-4A90E2?style=flat)

AI-powered fitness form analysis using computer vision and machine learning. Real-time pose detection for multiple exercises with form scoring and personalized feedback.

**Tech Stack**: Python · MediaPipe · OpenCV · React

**Links**: 
- 🔗 [Repo](https://github.com/Rishi-Mad/Fit-Friend)

<details>
  <summary><b>How It Works</b></summary>

1. **Pose Detection**: MediaPipe detects 33 body landmarks in real-time
2. **Exercise Recognition**: Automatically identifies exercise type from movements
3. **Form Analysis**: Computes joint angles and scores form quality
4. **Feedback Generation**: Provides personalized recommendations for improvement
5. **Progress Tracking**: Downloadable workout reports with key frames
</details>
