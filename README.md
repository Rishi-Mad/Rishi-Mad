### 2. RISC-V CPU Simulator ![Status](https://img.shields.io/badge/status-in%20progress-333333?style=flat)

Low-level CPU simulator implementing RISC-V architecture with support for custom instructions and pipeline visualization.

**Tech Stack**: C · RISC-V Assembly

**Links**: 
- 🔗 [Repo](https://github.com/Rishi-Mad/RISC-V-CPU-simulator)

<details>
  <summary><b>Implementation Details</b></summary>

- **Pipeline Stages**: Fetch, Decode, Execute, Memory, Writeback
- **Hazard Detection**: Data and control hazard handling
- **Custom Extensions**: Support for custom RISC-V instructions
- **Debug Interface**: Step-through execution and register inspection
</details>

### 3. Custom Chess Engine ![Status](https://img.shields.io/badge/status-in%20progress-333333?style=flat)

High-performance chess engine with advanced move generation, evaluation, and AI opponent using minimax with alpha-beta pruning.

**Tech Stack**: Python · Chess Logic · AI Algorithms

**Links**: 
- 🔗 [Repo](https://github.com/Rishi-Mad/Custom-Chess-Engine)

<details>
  <summary><b>Engine Features</b></summary>

- **Move Generation**: Efficient legal move generation and validation
- **Position Evaluation**: Material, positional, and tactical evaluation
- **Search Algorithm**: Minimax with alpha-beta pruning and move ordering
- **Opening Book**: Database of common opening sequences
</details>

**Tech Stack**: Python · MediaPipe · OpenCV · React
